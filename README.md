# Prefix and Postfix Debugger in JS 🦄

A lightweight JavaScript demonstration focused on identifying and understanding prefix and postfix increment/decrement operator behaviors (++ / --) and how they affect expressions and variable values.

## 📌 Features

- ✅ Prefix vs Postfix Demonstration: Shows the difference between ++x / --x (change then return) and x++ / x-- (return then change);
- ✅ Edge-value Handling: Demonstrates behavior with single-digit values and zero to ensure expected arithmetic results;
- ✅ Clear Console Output: Prints both the expression output and the intermediate values so you can trace changes step-by-step.

### 🚀 🛠️ Usage

You can run this project locally using Node.js or paste the code into your browser's developer console.

### Running with Node.js ⚙️

Ensure you have Node.js installed: https://nodejs.org/

### Clone this repository:

git clone https://github.com/willpaes/prefix-postfix-debugger.git

### Execute the script:

bash
node pre-pos-debugger.js

### Navigate to the project directory:

bash
cd prefix-postfix-debugger
